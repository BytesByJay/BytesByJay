### Featured Projects

#### [Launchbox](https://github.com/BytesByJay/Launchbox)
**Self-Hosted Git-Push-to-Deploy Platform**

A self-hosted deployment platform inspired by Heroku. Push code to Git and Launchbox automatically builds, containerizes, and deploys applications using Docker, with Traefik handling routing and SSL.

**Tech:** Python, Docker, Traefik, Linux, Git Hooks

---

#### Evaluation Engine
**Multi-Agent AI System for Automated Exam Evaluation**

Built a multi-agent evaluation system using Google ADK and Gemini to evaluate handwritten exam responses, generate research-backed grading rubrics, and identify learning gaps using knowledge graph mapping.

**Tech:** Google ADK, Gemini, Vertex AI, Tavily, Spanner Graph, Model Armor

---

#### [PySniffer](https://github.com/BytesByJay/pysniffer)
**Python Performance Profiling Package**

A decorator-based Python profiling package that measures wall-clock time, CPU time, and peak memory usage per function, with configurable logging and cProfile-backed call statistics.

**Tech:** Python, cProfile, Performance Profiling

---

#### [C-Web](https://github.com/BytesByJay/C-web)
**Minimal HTTP Server in C**

A lightweight HTTP/1.0 static file server built using standard C and raw sockets, implementing request parsing, response generation, and signal-based shutdown without external dependencies.

**Tech:** C, Socket Programming, HTTP
